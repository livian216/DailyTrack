# DailyTrack v1.1.1 发布说明

发布日期：2026-05-17

## 版本概览
v1.1.1 是一次以“升级可用性 + 数据延续性”为核心的稳定性发布，重点解决用户在卸载重装/升级安装后历史数据路径丢失、升级流程繁琐的问题。

## 重点更新
### 1. 安装升级流程增强
- 新版安装包会检测本机是否存在旧版 DailyTrack。
- 检测到旧版时，安装程序会自动触发旧版卸载，并在卸载完成后继续安装新版。
- 若自动卸载失败或被取消，安装将中止并提示用户先手动卸载，避免出现半升级状态。

### 2. 升级过程稳定性优化
- 安装阶段支持处理旧版进程占用问题，降低因文件被占用导致安装失败的概率。

### 3. 数据目录配置持久化
- 数据目录配置文件改为固定保存在：
  - `%APPDATA%\\DailyTrackConfig\\app_config.json`
- 升级/重装后将优先读取该配置，减少“自定义目录丢失”的情况。
- 兼容旧配置迁移：若检测到安装目录旧配置文件，会自动迁移到新位置。

## 用户收益
- 无需手动先卸载旧版，再安装新版。
- 升级后更容易保持原有数据目录和历史记录连续性。
- 安装失败风险和版本切换成本降低。

## 已知说明
- 本版本仍为同一产品标识（AppId）下升级，适用于官方同系列安装包。
- 卸载默认不删除用户数据目录；建议升级前继续保留导出/备份习惯。

## 验证建议
- 旧版存在场景：直接运行 v1.1.1 安装包，验证自动卸载 + 继续安装。
- 旧版运行中场景：保持旧版打开，执行安装，验证占用处理。
- 数据延续场景：升级后检查自定义目录历史数据是否可继续读取。
